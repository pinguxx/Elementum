# Elementum Benchmarks

> Generated by `node tools/benchmark.js --write` (source: [`tools/benchmark.js`](./tools/benchmark.js)).
> DOM mount benchmarks run in `happy-dom` (Node.js) and measure JS framework overhead, not browser layout/paint.

## Methodology & Environment

- **Date:** 2026-11-19
- **Node.js:** `v24.22.1`
- **OS:** win32 10.0.26300 (x64)
- **CPU:** Intel(R) Core(TM) i9-14900KF (32 logical cores)
- **Protocol:** 3 unmeasured warm-up iterations followed by 15 measured repetitions per case; reporting median (p50), p95, min, and max.

## Results

| Benchmark | Median (p50) | p95 | Min | Max |
| :--- | ---: | ---: | ---: | ---: |
| Signals: 1,000 updates (signal->computed->effect) | 0.28 ms | 3.96 ms | 0.22 ms | 3.96 ms |
| Signals: 10,000 updates (signal->computed->effect) | 1.68 ms | 1.85 ms | 1.66 ms | 1.85 ms |
| Signals: 10,000 batched writes (batch()) | 0.10 ms | 0.34 ms | 0.09 ms | 0.34 ms |
| DOM Mount + Unmount: 100 <el-badge> (happy-dom) | 5.22 ms | 10.87 ms | 4.36 ms | 10.87 ms |
| DOM Mount + Unmount: 500 <el-badge> (happy-dom) | 28.66 ms | 41.54 ms | 22.11 ms | 41.54 ms |
| DOM Mount + Unmount: 1000 <el-badge> (happy-dom) | 55.03 ms | 72.87 ms | 47.55 ms | 72.87 ms |
| SSR DSD: 1,000 <el-button> pure-Node renders | 6.20 ms | 12.56 ms | 5.45 ms | 12.56 ms |
