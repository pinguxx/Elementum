## 4. Reproducible Verification Instructions

Run these commands from a clean clone to independently reproduce all verification claims:

```bash
# 1. Exact lockfile install
npm ci

# 2. Catalog diff, release-metadata sync, strict TypeScript (core + React), and gzip budgets
npm run catalog:diff
npm run check:release
npm run typecheck
npx tsc --noEmit --strict --lib es2022,dom --target es2022 src/react/index.d.ts
npm run check:size

# 3. Full unit, fuzz, contract, SSR & MCP security suite (>= 95% line coverage enforced)
node --test --experimental-test-coverage --test-coverage-lines=95

# 4. External tarball consumer, Real React 18 & 19 StrictMode, and 5 Vite starter builds
npm run verify:consumer
npm run verify:react
npm run verify:starters

# 5. Real-browser Playwright E2E + WCAG 2.2 AA axe-core & visual snapshot regression
npx playwright install chromium
npm run test:e2e
npm run test:visual

# 6. Regenerate permanent quality & audit reports
npm run quality:report
npm run audits:report
```
