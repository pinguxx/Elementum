# Elementum Starter Projects

Copy-paste starter templates for getting started with `@wcomp/elementum` across different frameworks and architectures:

| Starter | Stack | Description |
| ------- | ----- | ----------- |
| [**vanilla-html**](./vanilla-html) | HTML5 + unpkg CDN | Zero-build, pure browser Custom Elements with micro-signals counter & dialog. |
| [**next-app-router**](./next-app-router) | Next.js 14+ / React 18/19 | Server-Side Rendering with pure Node.js Declarative Shadow DOM (`renderComponentToDSD`). |
| [**react-19**](./react-19) | React 19 + TypeScript + Vite | Native React 19 Custom Elements integration with properties, boolean attributes, and events. |
| [**vue-3**](./vue-3) | Vue 3 + Vite | Native Custom Elements integration with `compilerOptions.isCustomElement`. |
| [**svelte-5**](./svelte-5) | Svelte 5 (Runes) + Vite | Zero-wrapper Svelte 5 Runes integration with Elementum Custom Elements. |
| [**ai-chat**](./ai-chat) | HTML5 + AI Specialist Elements | Agent UI with `<el-prompt-input>`, `<el-reasoning-card>`, `<el-tool-call>`, and `<el-streaming-text>`. |
| [**framework-comparison**](./framework-comparison) | React vs. Vue 3 vs. Vanilla | Same Team Directory app built 3 ways with measured LOC, bundle overhead, and ergonomics. |
