# Elementum Starter Projects

Copy-paste starter templates for getting started with `@wcomp/elementum` across different frameworks and architectures:

| Starter | Stack | Live Demo | Description |
| ------- | ----- | --------- | ----------- |
| [**vanilla-html**](./vanilla-html) | HTML5 + unpkg CDN | [Live Demo](https://elementum-sage.vercel.app/starters/vanilla-html/index.html) | Zero-build, pure browser Custom Elements with micro-signals counter & dialog. |
| [**next-app-router**](./next-app-router) | Next.js 16 / React 19 | [Live Demo](https://elementum-next-dsd.vercel.app) | Server-Side Rendering with pure Node.js Declarative Shadow DOM (`renderComponentToDSD`). |
| [**react-19**](./react-19) | React 19 + TypeScript + Vite | — | Native React 19 Custom Elements integration with properties, boolean attributes, and events. |
| [**vue-3**](./vue-3) | Vue 3 + Vite | — | Native Custom Elements integration with `compilerOptions.isCustomElement`. |
| [**svelte-5**](./svelte-5) | Svelte 5 (Runes) + Vite | — | Zero-wrapper Svelte 5 Runes integration with Elementum Custom Elements. |
| [**angular**](./angular) | Angular 19+ (Standalone) | [Live Demo](https://elementum-angular.vercel.app) | Standalone Angular 19 component with `CUSTOM_ELEMENTS_SCHEMA`, `ngDefaultControl`, and WebMCP `<el-form>`. |
| [**ai-chat**](./ai-chat) | HTML5 + AI Specialist Elements | [Live Demo](https://elementum-sage.vercel.app/starters/ai-chat/index.html) | Agent UI with `<el-prompt-input>`, `<el-reasoning-card>`, `<el-tool-call>`, and `<el-streaming-text>`. |
| [**framework-comparison**](./framework-comparison) | React vs. Vue 3 vs. Vanilla | [React](https://elementum-comparison-react.vercel.app) · [Vue](https://elementum-comparison-vue.vercel.app) · [Vanilla](https://elementum-sage.vercel.app/starters/framework-comparison/vanilla/index.html) | Same Team Directory app built 3 ways with measured LOC, bundle overhead, and ergonomics. |
