# AI Chat UI Starter

An interactive, zero-build AI Chat interface using Elementum's specialized AI components:

- `<el-prompt-input>`: Auto-resizing prompt composer with Enter-to-submit and action slots.
- `<el-reasoning-card>`: Collapsible thought disclosure with pulsing thinking indicator.
- `<el-tool-call>`: AG-UI compatible tool execution visualizer with arguments and result inspection.
- `<el-streaming-text>`: Token-by-token streaming animation with typing cadence and jitter.
- `<el-sources>`: Grounding citation pills and expandable references.

## Quick Start

Open `index.html` in your browser or run:

```bash
npx serve .
```
