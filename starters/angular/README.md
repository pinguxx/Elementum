# Elementum + Angular 19+ Starter

**Live Demo:** https://angular-wc-e102.vercel.app

Minimal standalone Angular 19 starter using `@wcomp/elementum` with `CUSTOM_ELEMENTS_SCHEMA`, `ngDefaultControl`, W3C WebMCP `<el-form toolname>`, and `<el-theme-switch>`.

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
