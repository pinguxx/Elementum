# React 19 + Elementum Starter

A modern Vite + React 19 + TypeScript starter demonstrating native Custom Elements support.

React 19 supports Custom Elements natively—properties, boolean attributes, and standard DOM events work directly on custom element tags without synthetic wrappers.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).
