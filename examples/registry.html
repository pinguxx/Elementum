Modern Web Components at Scale

Traditional component libraries bundle hundreds of kilobytes of runtime framework abstractions. Elementum leverages native Custom Elements v1 and Shadow DOM to deliver encapsulated, portable UI primitives with zero external dependencies.

"Simplicity is prerequisite for reliability." — Edsger W. Dijkstra

Core Architectural Pillars

  • Zero Dependencies: No React, no Tailwind CLI, no build lock-in.
  • Fine-Grained Signals: Micro-signals drive surgical DOM mutations.
  • Form Participation: Built on native ElementInternals.
